# 画风圣经：Kako 2D Studio 的画面

照着这份做。这是目标画面唯一的描述，没有参考图。

## 一段话说清画风
纯黑（`S().ink`）的火柴人：圆头，粗线条四肢、圆头端点，朝向光源的一侧有一道细细的轮廓光。他们在**暗调、电影感、平涂的矢量场景**里表演：每个场景一个强光源（夕阳窗户、路灯、体育场射灯、显示器），深紫或海军蓝的阴影，暖琥珀色高光，柔和的光晕，飘浮的灰尘或雨，浅景深（前景和背景虚化），缓慢不停的运镜，上下遮幅，胶片颗粒和暗角。角色靠**一件**有颜色的衣服或配饰区分。脸很简单：白色圆点或圆环眼睛、简单的白色嘴形，偶尔有眉毛。节奏靠这些打断：整屏的大脸特写、粒子悬在半空的定格时刻、发光的数字和图表、讲原理时的海军蓝蓝图，以及用同一套人物和配色做的低多边形 3D 镜头。整体感觉是「一部由摄影指导打光的火柴人电影」：形状简单，光很讲究。

## 人物
- **结构**（由 `drawFigure` 处理）：头圆半径 26 个骨架单位，躯干 15，四肢 11–13、圆头端点，脚是朝前的短线，正常大小时不画手指。只有插入特写才画手和手指（粗胶囊形）。
- **远近明暗：** 近侧的手臂和腿是纯墨色，远侧的用 `inkFar`（深紫灰）。这是自动的。
- **每个被照亮的人物都有轮廓光：** 传 `rim: { color: M.rim, dir: [dx, dy] }`，`dir` 从人物指向光源。窗户或太阳在背后 → `[0, -1]`。光从左边来 → `[-1, -0.3]`。1080p 下宽 4–5。黑色人物放在暗背景上全靠轮廓光才看得清，所以一个都不能漏。
- **标志物**（每个反复出现的角色正好一个醒目颜色，全片完全一致）：橙红连帽衫 `#d64a33`、黄帽子 `#f2c21a`、粉毛线帽 `#f29ac0`、绿帽子 `#3fb950`、蓝 T 恤 `#3a6ea5`、紫运动服 `#8a5ad6`、白大褂 + 圆眼镜（科学家）、黑风衣 + 礼帽 + 墨镜（神秘导师或反派，常常半身在阴影里）、任意强调色的头带（运动员）、马尾或丸子头增加变化。小孩：`kid: true`（72% 大小）。背景人物和人群：纯墨色，不带颜色。
- **脸**画在人物朝向的一侧（四分之三侧面）。表情是主要的表演手段，**跟着词的节拍换**，不要随便换：
  `neutral, smile, happy, joy, surprised, shocked, scared, worried, nervous, angry, determined, sad, cry, smirk, sleepy, thinking, confused, awe`。
  每 2.5–4 秒眨一次眼（`blink: (t % 3.1) > 3.0`，每个角色周期不同）。
- **说话：** 只有角色说一句台词时才动嘴。用 `talk: talkAmount(info.globalT, lineStart, lineEnd)`（按真实的词时间驱动），头周围加 2–3 圈淡淡扩散的 `FX.rings`。旁白永远不对口型。
- **表演：** 姿势要能当剪影看懂。用 `POSES` 加 `posesAt(t, [[0,'stand'],[0.6,'point']])`，过渡约 0.3 秒；站着或坐着的人包一层 `breathe(pose, t, 1, seed)`，没有人是僵住的。例外是时间暂停的时刻：世界冻结，只有主角在动。走路和跑步用 `walkPose(phase, {run})`，x 方向按相应速度移动（走 ≈ 160 单位/秒，跑 ≈ 420 单位/秒；走 phase = t × 2π × 0.9，跑 × 1.6）。超高速残影用 `trail: {count:4, dx:-40}`。
- **大小：** 全景 `s` ≈ 0.8–1.2（人物占画面高度 15–25%）。中景 `s` ≈ 1.5–1.8。情绪特写用 `bigFace`（1080p 下半径 280–360，头略低于画面中心，肩膀被画框下沿切掉，受光一侧有一道月牙形轮廓光）。人物一定站在地面上并有接触阴影（自动），不能飘着。

## 场景和环境
- 用**平涂形状和柔和的线性渐变**搭：不描边、不用照片、不用剪贴画、不用 emoji。纹理只限于地板线、窗棂、百叶窗和亮着的窗格。
- **明暗结构：** 画面 60–75% 是暗的中间调（墙和地面来自 mood，通常用 `shade(c, -0.3)` 压暗），1–3 个亮点（窗户、灯、屏幕、射灯、夕阳）。**把黑色人物放在最亮的区域前面**（窗户、光池、发光的屏幕），剪影才看得清。
- **分层**，用 `layer(g, cam, depth, fn)` 做视差：天空 0.1–0.2 → 天际线 / 山 0.3–0.4 → 后墙 / 立面 0.5–0.6 → 地面 / 道具 0.8–0.9 → 人物 1.0 → 虚化前景 1.5–1.8（`blurLayer(g, 8–14, fn, cam, 1.7)`）。大多数中景前面都该有点虚化的东西（玻璃杯、植物、栏杆、人群的后脑勺、另一个角色的肩膀）。
- **窗户是标志性元素。** 大窗户，有窗棂，后面是天空渐变（夕阳、金色，或者夜晚亮着窗户的天际线），太阳或月亮的光晕，有时有百叶窗。夜晚街道：房屋立面上亮着暖色窗户、台阶、带光锥的路灯、停着的车、圆形剪影的树。
- 从脚本里构思的常见场景：实验室、咖啡馆、卧室（月光照在床上）、厨房、教室、办公室、医院、更衣室、体育场（一排排观众、射灯架、大屏幕）、街道、天台、夕阳下的码头、夜路、公园、机场、太空。每个场景写成可复用的 `sets/<名字>.js` 函数，锚定 `GY`（地面线：`E.H * V(0.8, 0.68)`）和 `CX = E.W/2`。墙、地面、天空延伸到画框外很远，运镜时不露边。
- **几乎每个镜头都有氛围：** 室内飘灰尘（`FX.dust`），暴雨和夜晚有雨丝（`FX.rain`），时间暂停时有悬停的水珠或气泡（`FX.drops`），夜空有星星，亮光源上横一道镜头光（`FX.lensStreak`），太阳和窗户打出光束（`FX.godRays`），还有柔和的雾带。

## 光和颜色
- 每个场景选一个**情绪**：`M = mood('night')` 得到 `sky[], ambient, key, rim, wall, floor, dark, practical, grass, road, fog`。所有颜色都从 `M`、`S()`（配色 token）或角色表里取。不要写死颜色，这样换配色才会生效。
- 情绪跟着故事走：紧张、吓人的节拍更暗更冷（night / storm / interiorCool），胜利、温情的节拍更暖（golden / dusk / interiorWarm），讲解用 `void` / 蓝图。
- **每个镜头一个主光。** 把光源画出来（太阳、灯或窗户），再让光溢出来：光源周围 `glow()`，下面地上 `FX.pool()`，灯打出 `FX.lightCone()`，窗户和太阳打出 `FX.godRays()`。
- 全局调色来自所选配色，自动作用于每一帧最终画面（2D 和 3D 都一样）：分通道的 lift/gamma/gain（lift 给暗部染色，gain 给亮部染色）、对比度、饱和度、暗角、颗粒。泛光只作用于 3D。所以场景必须用 mood 和 style 的颜色：这样每种配色才看起来不一样。

## 镜头（永远不完全静止）
每个镜头都要动：慢推（镜头内 `z` 从 1.0 到 1.05–1.10）、横移（`x` ±20–60）、揭示时慢拉、轻微倾斜（`r` ±0.02）表现不安，或者冲击时抖动（`shake(t, amp)`）。运镜用 `ease.inOut`，急停用 `ease.out`。

**镜头词汇**（全片都要用到，大致按这个比例）：
1. **交代全景**（10%）：场景加上小小的人物，慢推。每个新场景开头用。常用 3D。
2. **中景双人镜头**（25%）：侧面，两人面对面，对话和动作。
3. **过肩镜头**（10%）：前景一个大大的虚化剪影（`blurLayer`，深度 1.6），另一个人清晰。
4. **整屏大脸特写**（`bigFace`，10–15%）：反应、恍然大悟、「你」的时刻、台词。背景是当前场景，虚化压暗（`blurLayer` + `veil`）。
5. **插入 / 微距**（10%）：手、手机屏幕、手表、球、杯子、门把手。大、简单、背景虚化。
6. **俯视 / 图解视角**（5%）：比如从上往下看桌面，有一条虚线轨迹和时间标签。
7. **定格 / 时间暂停**（标志性时刻，每支片子 1–3 次）：粒子悬在空中、冷色调、角落徽标（`100x`）、缓慢的光圈、缓慢的旋转，只有主角在动。用 `flash` 转场和 `freeze` 音效进入。
8. **3D 环绕 / 穿行**（大约每分钟一个）：体育场、街道、大厅这类大空间，用 `three-kit`（见 engine-api.md 的 three-kit）。
9. **数据卡 / 界面**（按需）：旁白念到的每个数字都出现在画面上，念到时动起来。
10. **蓝图原理图**：讲解 / 科学的段落（海军蓝网格、浅蓝线稿、金色高光，标签和词同步）。
11. **标题卡**：在电影感全景上叠发光的标题（常放在冷开场钩子之后）。
12. **片尾**：问题、评论气泡、订阅按钮、全体角色排成一排。

**遮幅（`bars`）：** 默认 `wide`（2:1）。`scope`（2.39:1）用于戏剧性的时刻：标题、定格、高潮和强烈的特写。全屏界面或蓝图想要满屏就用 `none`。镜头之间遮幅会平滑过渡。

## 剪辑和转场
默认硬**切**（80% 以上）。进入定格、时间暂停、超能力时刻和大领悟用 **flash**（白闪）。时间跳跃和换章用 **dip**（黑场）。温柔或梦幻的时刻和标题卡用 **fade**。场景之间有活力的跳转用 **whip**（甩镜）。钻进讲解用 **zoom**。保持连续性：同样的服装、同样的视线方向（对话中主角在左、面朝右）、同一场戏里每个镜头的场景结构一致。

## 画面图形和文字
- **字体：** 标题和大字用 Fredoka Bold（英文全大写、加字距、暖色光晕）。标签和数字用 Nunito Black。片尾问题用 Playfair Display Black Italic。中文字自动回落到思源黑体 Noto Sans SC（见下一节）。
- **颜色：** 关键数字用金色 `S().ui.gold`，警示数值用珊瑚色 `ui.accent`，标签用奶油色 `ui.cream`，蓝图用 `ui.blueprint`。
- **工具箱（`ui2d`）：** `titleCard`、`bigLine`（一句问题或章节标题）、`badge`（角落倍数或天数）、`readout`（「正常：0.25 秒」）、`dataCard`（标题、计数器和一条画出来的曲线）、`compareBars`、`dimension`（带箭头的尺寸「30 米」）、`callout`（引线标签）、`meter`、`blueprint` + `lineFigure`、`bubble`、`endScreen`、`captions`。
- 旁白念到的每个数字或量都要出现在画面上，用 `wordTime()` 同步。字要少：同时最多 1–2 个短标签，除了标题、问题和片尾，不出现整句话。
- 图形用 `ease.outBack` 缩放弹出，配 `pop` / `blip` 音效。切镜之前先淡出。

## 中文画面字（配音是中文时）
- 画面上的字全部用中文，和旁白的说法一致（旁白说「七下」，标签写「7 次」或「七下」都行，但不要写成英文）。
- **字数要少：** 标题卡每行 ≤ 8 个字，最多两行（如「如果你的心跳 / 慢十倍？」）；标签和读数 ≤ 6 个字；片尾问题一句、≤ 16 个字。
- 画面上的数字用阿拉伯数字（`7 次`、`10 倍`、`20 秒`），读起来更快；旁白里怎么念不受影响。
- 中文不做全大写、不加大字距（`spacing` 设 0–2）；英文标题照旧大写。
- 片尾问题是中文时，`endScreen` 自动改用标题字体、不倾斜。订阅按钮、标题卡、`bigLine` 的默认文字跟着配音语言走（config.json 的 `lang`）：中文是「订阅」「这些是真的吗？」，英文是 Subscribe、IS ANY OF THIS REAL?。
- 用 `wordTime('十倍', info.shot.start)` 这样的中文词来同步图形；中文旁白是按字对时的，词可以落在任意字上。
- 字幕（`captions: true`）按字数和标点自动分组：横屏每组 ≤ 16 个字、竖屏 ≤ 11 个字，句中标点隐藏，问号感叹号保留，正在念的字高亮成金色。

## 故事惯例（「如果……会怎样？」类叙事；只用脚本里有的内容）
冷开场钩子（一个戏剧性的瞬间，常常是定格）→ 标题卡 → 日常生活和发现 → 带具体数字的升级 → 代价或反转 → 高潮 → 收尾 →「这些是真的吗？」（蓝图科学段）→ 片尾问题和行动号召。讲解、历史、纪录片类脚本用同一套词汇：角色演示例子，数据卡承载数字，蓝图讲清机制。

## 不要
不要写实、不要给人物加渐变、不要粗描边、照片、emoji、剪贴画，不要平的白背景（白闪除外）。不要静止镜头。被照亮的场景里不要没有轮廓光的人物。旁白不对口型。不要大段文字。同时聚焦的人物不超过约 4 个（人群可以）。人物不能飘着。服装颜色不能变。不要什么都放正中间（用三分法；大脸特写例外）。不要写死、无视 `mood()` / `S()` 的颜色。场景里不要用 `Math.random()` 或 `Date.now()`（会破坏确定性；用 `rng(seed)` 和 `t`）。

## 9:16 竖屏规则
逻辑舞台是 1080×1920（`E.vertical === true`）。凡是和画面比例有关的大小和位置都用 `V(横屏值, 竖屏值)`。
- **景别更近：** 以中景和特写为主。全景变成竖着叠的结构（天空 → 建筑 → 地面），人物放在中间三分之一。
- **安全区：** 脸和字放在中间约 900×1500 的范围里，避开平台界面。字幕在约 79% 高度处（config.json 里 `captions: true`）；长句会自动缩小。
- 原理图竖着排（眼睛在大脑上面，大脑在手臂上面）。数据卡更高。字号更大（UI 函数已经用了 `V()`）。
- 遮幅默认 `none`，`scope` 给细遮幅。地面线 `GY = E.H * 0.68`，让人物在字幕上面（y ≈ 0.79·H）。标题卡和片尾镜头设 `"captions": false`，免得字幕和画面字重复。
- 渲染前用 `--sheet` 检查竖屏效果。只为 16:9 设计的镜头通常会把主体切掉。
