# 故事拆解（创作这一步）

把整份转写稿读两遍。然后写 `story/bible.md`（简短、实用）：
- **一句话梗概和基调**（惊奇 / 悬疑 / 喜剧 / 剧情），脚本是第二人称时写清「你」是谁。
- **角色表。** 每个反复出现的角色：id、身份、服装 `{top, color, head, headColor, face, legs, gloves, kid}`、标志色、性格、最常用的表情。每个反复出现的角色有且只有一个醒目的饱和色标志物（见 style-bible.md 的「人物」）。服装写进 `scenes/cast.js`。
- **场景。** 每个场景：名字、情绪（`day|golden|dusk|night|storm|interiorWarm|interiorCool|void`）、主光从哪里来、窗外景、3–6 个标志性道具、分层（天空 → 远景 → 中景 → 地面 → 前景）。
- **视觉母题：** 和故事绑定、反复出现的视觉手法，比如表现时间变慢的「水珠悬停」、角落的倍数徽标、心电图线、代表某种能力的颜色。
- **分幕 / 音乐规划：** 每段一个情绪和强度（见 sound-design.md）。

然后**重写 `story/shots.json`**（结构见 engine-api.md 的 story/shots.json）。每个镜头填：
`id, start, end, line, scene`（一句具体描述画面的话，例如「过肩：前景是虚化的阿杰肩膀，小林站在窗边，下雨，慢推」）、`set`、`bars`、`in`（转场）、`sfx`、`amb`、`notes`。

`line` 照抄这个镜头对应的旁白原文，一个字都不改。

节奏规则：
- 镜头**首尾相接**：每个 `end` 等于下一个的 `start`。第一个从 0 开始，最后一个结束在 `duration`，也就是配音时长再加约 1.5 秒。
- 在短语边界切。镜头比它要表现的那句话**早 0.1–0.2 秒**开始。
- 镜头时长**中位数 2–3.5 秒**。快动作：0.8–2 秒一切（一句话拆成好几个镜头）。情绪或对白镜头：停 4–8 秒。超过约 10 秒必须有新动作或新运镜。
- 每到一个新场景，先给一个交代镜头（2D 全景或 3D）。
- 大约**每分钟旁白 15–25 个镜头**。中文语速快，一句话常常包含好几个画面，可以拆得更碎一些。

给用户发一段 5–10 行的摘要：角色、场景、镜头数、每一幕的视觉看点。用户没有异议就继续。
